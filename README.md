# Text Wizard — персональное офлайн‑приложение для работы с текстом

## 🎯 Описание

**Text Wizard** — персональное приложение для работы с текстом, оптимизированное для смартфона. Все данные хранятся локально на устройстве, приложение работает полностью офлайн.

## ✨ Основные возможности

### 📝 Текстовый редактор

- Полнофункциональное редактирование с историей изменений
- Инструменты форматирования (регистр, очистка)
- Поиск и замена текста
- Статистика (символы, слова, строки). Подсчет символов: без пробелов/переносов, с учетом графем (корректно считает эмодзи/диакритику)
- Сохранение в историю

#### Кнопки и действия редактора

- **Нижняя панель действий (sticky внутри экрана редактора)**
  - **Отменить** (`undo`) — шаг назад по истории изменений.
  - **Повторить** (`redo`) — шаг вперед по истории изменений.
  - **Копировать** (`handleCopy`) — копирует текст; показывает уведомление об успехе/ошибке.
  - **Вставить** (`handlePaste`) — вставляет из буфера; при недоступности предлагает альтернативы.
  - **Сохранить** (`saveToHistory`) — добавляет текущий текст в историю (определяет язык ru/en автоматически).
  - **В заметки** (`transferToNotes`) — переносит текст в раздел заметок (кнопка видна, если есть текст).
  - **В Suno** (`transferToSuno`) — переносит текст в Suno Editor (кнопка видна, если есть текст).

- **Навигация по разделам** — через нижнюю панель навигации (BottomNav), закреплённую у нижнего края приложения. При переключении вкладок фокус снимается, чтобы не вызывать клавиатуру самопроизвольно.

- Примечание: действие **«Очистить»** (`clearText`) перенесено в раздел «Форматирование» и отсутствует на частой панели, чтобы избежать случайного стирания текста.

- **Быстрые действия (режим «Профессиональный»)**
  - **Заглавный** — весь текст В ВЕРХНЕМ РЕГИСТРЕ.
  - **Прописной** — весь текст в нижнем регистре.
  - **Удалить пробелы** — обрезает пробелы по краям (`trim`).
  - **Удалить лишние пробелы** — сжимает повторяющиеся пробелы до одного.

- **Поиск и замена**
  - Поля: **Найти**, **Заменить на**.
  - **Заменить все** (`findAndReplace`) — глобальная замена в тексте.

- **Форматирование**
  - **Заглавный регистр слов** (`transformCase('title')`) — каждое слово с заглавной буквы.
  - **Первая заглавная** (`transformCase('sentence')`) — первая буква предложений заглавная.
  - **Удалить все** (`clearText`) — очищает поле.
  - **Удалить пробелы** (`removeExtraSpaces`) — сжимает пробелы и убирает лишние по краям.
  - **Удалить дубликаты** (`removeDuplicateLines`) — удаляет одинаковые строки.
  - **Удалить пустые строки** (`removeEmptyLines`) — убирает пустые/пробельные строки.
  - **Сортировать строки** (`sortLines`) — сортирует строки по алфавиту.
  - **Подсчитать символы** (`countCharacters`) — показывает количество символов и слов.

- **Преобразование списков**
  - Поле **Разделитель** — символ(ы) для разделения (по умолчанию запятая).
  - **Inline → Список** (`inlineToList`) — разделяет по разделителю на построчный список.
  - **Список → Inline** (`listToInline`) — склеивает строки в одну строку через разделитель.

- **Markdown**
  - **Жирный** (`addMarkdown('bold')`) — оборачивает в `**...**`.
  - **Подчеркнутый** (`addMarkdown('underline')`) — оборачивает в `__...__`.
  - **Код** (`addMarkdown('code')`) — оборачивает в `` `...` ``.
  - **Заголовок** (`addMarkdown('heading')`) — добавляет `#` в начало.
  - **Разделитель** (`addMarkdown('separator')`) — добавляет строку `---`.
  - **Убрать Markdown** (`removeMarkdown`) — снимает базовое оформление (`**`, `__`, `` ` ``, `#`, `---`).

- **Специальные символы**
  - Панель специальных символов (`<SpecialCharsManager />`) — быстрый ввод часто используемых знаков.

- **Нижняя панель (всегда видима)**
  - Иконки быстрых действий: Отменить, Повторить, Копировать, Вставить, Сохранить.
  - Кнопка **Очистить** — очищает текст.

- **Статистика**
  - Бейджи внизу редактора: **Символов**, **Слов**, **Строк**.

#### 1. Редактор — расширенные возможности

##### 1.1 Базовое редактирование

- Неограниченная история Undo/Redo (персистентная между сессиями).
- Автосохранение и восстановление после сбоя.
- Split‑view: два синхронизированных просмотра одного файла.

##### 1.2 Поиск / Замена

- Поддержка регулярных выражений с подсветкой совпадений.
- Интерактивный превью замен до применения.

##### 1.3 Форматирование — расширенный каталог

- Все операции отображают превью и откатываются одним Undo.

- Регистр
  - Ctrl+Shift+U UpperCase
  - Ctrl+Shift+L lowerCase
  - Ctrl+Shift+T TitleCase
  - Ctrl+Shift+S SentenceCase
  - Toggle (переключение регистра)
  - RandomCase (случайные регистры символов)

- Идентификаторы
  - Alt+Shift+1 camelCase
  - Alt+Shift+2 snake_case
  - Alt+Shift+3 kebab‑case
  - Alt+Shift+4 PascalCase

- Символы / Псевдо‑шрифты
  - Alt+↑ Superscript
  - Alt+↓ Subscript
  - Alt+S SmallCaps
  - Alt+B Bold Serif, Alt+I Italic Sans, Alt+M Monospace, Alt+F Fraktur, Alt+D Double‑Struck

- Структура текста
  - Alt+W Wrap ≤N — жёсткий перенос (по умолчанию 80 симв.)
  - Ctrl+Alt+P Prefix, Ctrl+Alt+S Suffix, Ctrl+Alt+N Numbering строк
  - Ctrl+Alt+B Bullet, Ctrl+Alt+U Unbullet, Ctrl+Alt+C Checklist
  - Ctrl+Alt+I Reindent Tabs↔Spaces (с выбором размера отступа)
  - Ctrl+Alt+L Sort Lines (A→Z, Z→A, по длине, случайно)
  - Alt+D Deduplicate, Alt+R Shuffle Paragraphs

- Очистка
  - Alt+T Trim Trailing Spaces
  - Alt+E Ensure EOF Newline
  - Alt+U Normalize Unicode NFC/NFD
  - Alt+Shift+D Strip Diacritics
  - Alt+H Remove HTML, Alt+M Remove Markdown, Alt+B Remove BBCode

- Кодирование / Шифрование
  - Ctrl+E HTML/JSON/XML Escape ⟷ Unescape
  - Ctrl+Shift+B Base64 Encode/Decode
  - Ctrl+R ROT13 / Caesar ±N

- Трансформация текста
  - Alt+Shift+R Reverse Text
  - Alt+Shift+M Mirror
  - Alt+Shift+U Upside‑Down
  - Alt+Shift+T Transliterate Latin ↔ Cyrillic (ГОСТ 7.79, ISO 9, Passport)
  - Alt+X Extract Emails/URLs/Digits, Alt+Shift+X Remove Emails/URLs/Digits
  - Ctrl+Alt+T Insert Timestamp, Ctrl+Alt+U Insert UUID, Ctrl+Alt+L Insert Lorem Ipsum

- RegExp макросы
  - Ctrl+Shift+R Saved Patterns Manager
  - Каталог встроенных и пользовательских шаблонов
  - Presets для мгновенного удаления содержимого в (...), [...], <...> и т.д.
  - Add Preset: введите Pattern, Replacement, псевдоним и хоткей; шаблоны хранятся в локальном JSON (экспорт/импорт)
  - Пример пользовательского пресета для ("…"): `\(\"[^"\\]*\"\)`

### 📚 Система заметок

- Создание, редактирование и удаление заметок
- Поиск по содержимому
- Экспорт и импорт заметок
- Автосохранение

### 📖 История

- Отслеживание всех изменений текста
- Фильтрация по языку и типу
- Экспорт истории

### 🎵 Suno Editor

- Специализированный редактор для создания песен
- Система тегов: структура ([Verse], [Chorus] и др.), вокал, текстура, тон, эффекты, ритм, динамика, прогрессия, элементы, атмосфера, инструменты, качество, жанры, окружение
- Валидация структуры (проверка секций, пустых блоков, баланса куплет/припев)
- Предпросмотр с подсветкой секций и тегов
- Вставка тегов кликом и правым кликом (ПКМ — в рекомендуемое поле: Lyrics/Style/Exclude)
- Расширенные опции: Weirdness, Style Influence, Audio Influence
- Поля: название песни, исполнитель, описание стиля, исключаемые стили
- Экспорт в формат SUNO (JSON) одним кликом

## 🚀 Установка и запуск

### Требования

- Node.js 18+
- npm или yarn

### Установка

```bash
# Клонирование репозитория
git clone <YOUR_REPO_URL>
cd text-wizard

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## 📱 Мобильная оптимизация

Приложение оптимизировано для использования на смартфонах:

- Адаптивный дизайн
- Увеличенные размеры кнопок для сенсорного управления

## 💾 Локальное хранение данных

Все данные хранятся в localStorage браузера:

- Заметки
- История изменений
- Настройки приложения
- Песни Suno

### Экспорт данных

- Экспорт всех данных в JSON файл
- Резервное копирование заметок
- Перенос данных между устройствами

### Импорт данных

- Импорт из JSON файлов
- Восстановление из резервных копий
- Синхронизация между устройствами

## 🛠 Технологии

- **Frontend**: React 18 + TypeScript
- **Сборка**: Vite
- **Стили**: Tailwind CSS + shadcn/ui
- **Хранение**: localStorage
- **Мобильная разработка**: Capacitor
- **Тестирование**: Vitest + Testing Library

## 🧪 Тестирование

Проект использует современный стек для тестирования:

- **Vitest** — быстрый тест-раннер, интегрированный с Vite
- **@testing-library/react** — утилиты для тестирования React компонентов
- **jsdom** — DOM окружение для тестов

### Команды для тестирования

```bash

# Запуск тестов один раз
npm run test -- --run

# Запуск с отчетом о покрытии кода
npm run test:coverage

# Запуск с UI интерфейсом
npm run test:ui
```

Подробная информация о тестировании доступна в [TESTING.md](TESTING.md).

## 🔧 Настройка для личного использования

1. **Удалите ненужные зависимости** (уже сделано)
2. **Настройте Capacitor для мобильной сборки**:

   ```bash
   npm install @capacitor/cli @capacitor/core
   npx cap init
   npx cap add android
   npx cap sync
   ```

3. **Соберите для Android**:
   
   **Вариант A: С Android Studio (GUI)**
   ```bash
   npm run build
   npx cap sync android
   npx cap open android
   ```
   Подробности: [BUILD_APK.md](BUILD_APK.md)
   
   **Вариант B: Только командная строка (без Android Studio)**
   ```bash
   npm run build
   npx cap sync android
   cd android
   .\gradlew.bat assembleDebug  # Windows
   ./gradlew assembleDebug      # Linux/Mac
   ```
   Подробности: [ANDROID_CLI.md](ANDROID_CLI.md)
