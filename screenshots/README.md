# Screenshots

This directory contains screenshots showing how the Text Wizard app works on mobile devices.

## Purpose

This folder is used to store:
- Screenshots of the app running on phone/mobile devices
- Visual documentation of app functionality on Android
- User interface examples from real device usage

## File Organization

Please organize screenshots with descriptive names, for example:
- `editor-main-screen.png` - Main editor interface
- `text-formatting-tools.png` - Text formatting toolbar
- `clipboard-functionality.png` - Clipboard operations
- `mobile-keyboard-integration.png` - How the app works with mobile keyboards

## Supported Formats

Common image formats are supported:
- PNG (recommended for UI screenshots)
- JPG/JPEG 
- WebP

## Usage

Simply drag and drop your phone screenshots into this directory to document the app's functionality and user experience on mobile devices.
